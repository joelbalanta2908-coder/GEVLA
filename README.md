GEVLA
Gestión y Evaluación Virtual de Llamados de Atención

Descripción

Sistema web desarrollado como proyecto final del programa de Análisis y Desarrollo de Software (SENA) que automatiza y centraliza la gestión de llamados de atención disciplinarios dentro de la institución. GEVLA agiliza procesos, mantiene trazabilidad completa de casos y se alinea con la lógica operativa del SENA, incluyendo reglamentación del aprendiz, tipos de faltas y plantillas institucionales.

Tecnologías
-Backend: PHP con Framework Laravel
-Base de Datos: MySQL
-Funcionalidades: Correos automatizados (PHP Mailer), reportes, validación de reglas de negocio SENA

Funcionalidades Principales
-Registro y seguimiento de llamados de atención
-Automatización de notificaciones por correo
-Generación de reportes y documentación
-Integración con reglamentación y plantillas SENA
-Control de roles y permisos
